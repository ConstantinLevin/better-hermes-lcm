**Cost and compatibility conventions**

Costs are approximate incremental engineering effort, including meaningful regression tests: **S** ≈ half a day–two days; **M** ≈ three–seven days; **L** ≈ two–four weeks or more. Dependent items overlap and should not be added mechanically.

For every recommended port:

- Ordinary 256k compaction grouping must remain upstream-equivalent.
- New tuning preferences must use the specified window curve. Operator tools and optional presentation features can be introduced independently of automatic compaction.
- An abbreviated display must identify its source, indicate what is omitted, and provide working continuation or expansion.
- Model-backed operations must use operator-selected routing.
- Projection changes and repairs must preserve previous summaries, raw sources, provenance, and recoverable revisions.
