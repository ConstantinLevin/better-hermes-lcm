**B. Ranked unpinned guarantees**

The ordering weighs direct violations of the doctrine before performance and maintenance gaps.

**1. Provider-incomplete output must never become a summary.**

The real reader takes `response.choices[0].message.content`, sanitizes it and discards the rest of the envelope. Acceptance then checks whether the result is shorter than the source. Neither step checks completion status. The host exposes `finish_reason`, so this is not information necessarily unavailable to B. (`B/escalation.py:261,582`; `H/agent/auxiliary_client.py:6463`.)

**Probe:** a nonempty partial sentence with `finish_reason="length"` was accepted at L1 after one call.

**Surviving mutation:** accept the visible text specifically when the response reports length/incomplete termination. This is already the effective behavior; the inspected tests contain no corresponding finish-reason fixture. The response tests use controlled content without that status. (`T/test_lcm_engine.py:1402`; `T/tests` search for `finish_reason`.)

**Required test:** feed normalized complete, length-limited, incomplete, empty and malformed envelopes through the real adapter and public compaction path. Incomplete text must never be published; retry exhaustion must leave recoverable input and enter cooldown. A complete response above its advisory target must remain acceptable.

**2. Retained higher-depth nodes must traverse their actual archived children.**

Carry-over moves nodes by minimum depth. Child expansion requires each child to belong to the current session. (`B/dag.py:395`; `B/tools.py:1393,1497`.)

The apparent recovery test uses `depth=2, source_type="messages"`. The fork’s reset fixture uses empty source lists. Neither creates the graph whose ownership changes. (`T/test_lcm_engine.py:12715`; `F/test_marked_loss.py:165,219`.)

**Probe:** a new-session parent referencing an old-session child returned no expanded sources and a terminal pagination state.

**Surviving mutation:** reject every archived child reached from an authorized retained parent. The current fixtures admit precisely that behavior.

**Required test:** actual connected d2→d1→d0→messages, retain 2 and −1, repeated `/new`, restart, every public expansion level, and archived externalized payloads. Unrelated roots must remain unauthorized.

**3. Omission markers must survive final prompt assembly.**

The assembler appends an omission marker, then removes it when it would exceed the remaining summary budget. Its log warning is not visible provenance in the prompt. (`B/engine.py:6343`.)

`test_assembly_budget_skips_are_marked_with_node_ids` leaves enough room for its marker. It does not exercise the marker-removal branch. (`F/test_marked_loss.py:200`.)

**Probe:** tight-cap assembly omitted a large assistant message and returned only the user tail; the omission was reported solely in a log.

**Surviving mutation:** remove the marker only when the selected summaries/tail consume the budget. The existing happy-path marker test still passes.

**Required test:** adversarial budgets around marker size, including zero remaining summary budget. Assert the final provider-bound prompt names every omitted category and supplies usable recovery, while preserving the required fresh prompt.

**4. Publication must be atomic across node, sidecar and frontier.**

Leaf publication commits the node, writes metadata, then advances the frontier. Rotation advances its frontier before marker publication. These are separate failure points. (`B/compaction.py:1019`; `B/dag.py:250`; `B/node_meta.py:84`; `B/engine.py:6841,6876`.)

The WAL tests accurately describe themselves as PRAGMA and graceful-close tests. They are not interruption tests for this transaction. The async atomic-publication design tests are all marked strict xfail. (`T/test_crash_safe_wal.py:1,43`; `T/test_async_background_compaction_design.py:18`.)

**Surviving mutation:** commit a node or frontier, then fail the immediately following publication step. Ordinary round-trip tests do not distinguish this from an atomic implementation.

**Required test:** inject failure after every publication write, reopen storage, and assert either the complete old state or complete new state. Include rotation, leaf, condensation, sidecar and rollup invalidation boundaries.

**5. A leaf-loop deadline must bound blocked work, not just the number of returning calls.**

Lookahead uses `future.result()` without a timeout. Closing the executor afterward does not bound that wait. The fallback chain can also reuse a per-call timeout across attempts. (`B/leaf_pipeline.py:154,166,177`; `B/escalation.py:343`; `B/compaction.py:935`.)

The fork deadline test increments a fake clock by 0.03 seconds inside a summarizer that immediately returns. It proves the loop checks its clock between successful calls. (`F/test_weighted_chunking.py:105`.)

**Surviving mutation:** omit deadline enforcement while waiting on an individual future, or restart the full timeout for each fallback.

**Required test:** a controlled never-resolving call/future; bounded return through public `compress()`, correct contiguous partial publication and cooldown, no late publication afterward. Exercise serial, parallel, fallback, L2 and condensation.

**6. Index quality must distinguish a narrative index from a word bag.**

The prompt tests check strings. The doctor scores lexical entities, not events or relationships. Missing entities can fail while a faithful paraphrase scores worse; a word bag can pass while omitting what happened. (`F/test_index_contract.py:15,35,42`; `F/test_coverage_doctor.py:24`; `B/coverage_doctor.py:68`.)

**Probes:** a summary containing the extracted filenames, number and decision cue scored 1.0 without explaining the decision. Source text with no recognized entities also scored 1.0.

**Surviving mutation:** replace an off-focus topic’s account with its searchable identifiers, keeping all source IDs and required hint strings.

**Required test:** a fixture set with independently specified topics/events and distractor nodes. Present the rendered prefix to the operator-selected summarizer/reader, ask which node contains each event, and verify drill-down recovery. Include decisions, rejected approaches, reversals, completed work and topics located in the middle of long sources.

No test can mathematically guarantee semantic faithfulness for all outputs. This suite currently lacks even a standing behavioral gate for it.

**7. Focus guidance must not authorize topic loss.**

The L1 prompt still says to allocate 60–70% to focus and “Reduce resolved topics to one-liners or drop.” L2 contains the corresponding instruction. Two inherited assertions actively demand the latter text. (`B/escalation.py:456,506`; `T/test_lcm_core.py:4458,4484`.)

**Surviving mutation:** keep all new index-contract strings but strengthen the instruction to discard completed off-focus material. Positive substring tests do not detect contradiction.

**Required test:** a coherent full-prompt contract, including negative assertions against topic-dropping instructions, plus behavioral off-focus fixtures. The two inherited assertions must change when the production prompt changes.

**8. Low-window DAG identity needs an upstream oracle.**

The fork’s 256k chunking test has 40 small rows and modified tail/chunk controls. Its condensation test invokes the helper on a small single-depth case. Neither runs upstream. Parallel equivalence compares two B engines at 1M, with condensation disabled. (`F/test_weighted_chunking.py:40`; `F/test_condensation.py:49`; `F/test_parallel_leaf_sweep.py:39,67`.)

**Surviving mutation:** change low-window behavior only for a backlog larger than W, a rescue retry, a mixed-depth frontier or a repeated forced pass. The low-window fixtures do not cover those histories.

**Required test:** execute upstream at `.upstream-base` and B against identical controlled summaries and histories. Compare normalized source ranges, parent edges, depths, frontier membership and transition order after every operation—not only final node counts. Exclude only explicitly authorized pure-improvement representation changes.

**9. Every preference must interpolate linearly and reach every consumer.**

Independent endpoint maps are valuable. Intermediate checks cover only a few exact values; several merely assert “between endpoints.” The test called `test_status_payload_lists_every_anchor` checks only `fresh_tail_count`. (`F/test_window_scaling.py:48,66,74,86`; `F/test_window_scaled_engine.py:111`.)

**Executed surviving mutation:** for intermediate windows, replace fresh-tail interpolation with:

```python
round(32 + (400 - 32) * t * t)
```

Preserve the endpoints and status shape. All 13 cases in `test_window_scaling.py` passed.

**Required test:** independent expected interpolation and rounding for every setting at several interior windows; assert complete key sets and override behavior. Separately exercise each production consumer, because a correct resolver does not prove correct use.

**10. Recovery pagination must reconstruct the whole source, including a child summary’s own text.**

The raw-message tests establish useful offsets and some continuation, but the long-message example checks initial pages of repeated text rather than reconstructing a unique whole message. (`T/test_lcm_engine.py:23582,23697,23749`.)

Child expansion truncates a child summary and advances to the next child. The test explicitly expects that advancement. Known-node `describe` returns metadata rather than that node’s full summary, so it does not supply the missing continuation contract. (`B/tools.py:1410,1425,5320`; `B/dag.py:878`; `T/test_lcm_engine.py:24432`.)

**Surviving mutation:** skip the remainder of a truncated child summary, or introduce a gap after the second tested raw page.

**Required test:** follow public continuations to termination; concatenate unique Unicode/multiline content and compare exactly with storage. Cover child summary text separately from its underlying raw sources. Assert progress, no gaps, no duplicates and final completeness.

**11. Missing provenance must be reported as missing, not as successful exhaustion.**

Message expansion skips absent rows and advances the cursor. Child expansion similarly skips missing children. The orphan doctor checks message-sourced nodes from a default-limited node query; it does not validate every node-to-node edge. (`B/tools.py:1264,1393,6835`; `B/dag.py:463`.)

A related suspicion was **fine**: `source_message_ids` uses recursive `UNION`, not `UNION ALL`, so its distinct traversal should not be accused of the same cycle behavior as the separate `_node_matches_source` query. (`B/dag.py:770,828`.)

**12. “Failures never kill a turn” is currently narrower than the doctrine.**

The wrapper catches `SummaryUnavailableError`. The fork explicitly tests that an unexpected `ValueError` propagates; inherited engine tests likewise expect an unexpected error to escape. The real host reraises ordinary compression failures from its general exception branch. **Surviving mutation:** raise a storage/metadata error after a valid summarizer response. The typed-unavailable tests remain satisfied.

**Required test:** define and exercise a recoverable failure matrix at the public turn boundary: database busy/I/O, metadata failure, malformed response, timeout and rollup callback failure. Assert no fabricated node and a recoverable context. Explicit user cancellation should retain its distinct control semantics, not be swallowed.

**13. Parallel safety is not established across clones, host aborts or changed sessions.**

The mutex is per engine and process-local. The lock test uses two workers on one engine. The progress test replaces both production host-hook bindings with synthetic thread-local objects. (`B/leaf_pipeline.py:180`; `B/host_cooldown.py:165`; `F/test_parallel_leaf_sweep.py:152,185`.)

**14. Rotation’s existing regression now has the wrong oracle.**

After `compress()`, the old rotation test reads `nodes[0]` and requires nonempty pre-frontier provenance. B now creates a marker before that compression; the marker can satisfy these assertions. (`T/test_lcm_rotate.py:384,447,451,456,468`.)

**15. Condensation tests do not establish reachability from public pressure handling.**

Most fork condensation tests call `_maybe_condense` directly. Public non-sweep compaction can return before reaching condensation when no leaf was produced. Sweep and non-sweep also use different selection paths. (`F/test_condensation.py:49,63,78`; `B/compaction.py:1160`; `B/engine.py:5879`.)

**16. “Oldest first” and token-bounded condensation need adversarial groups.**

The “oldest first” fork fixture has one source depth. It does not distinguish oldest eligible group across depths from lowest-depth-first selection. Some high-pressure fixtures assign large token counts to tiny literal summaries. (`F/test_condensation.py:26,78`; `B/engine.py:5719,5879`.)

**17. Page-sized output does not imply page-sized I/O.**

**D. Cross-partition notes**

**Storage preservation, prompt inclusion and recovery are three different guarantees.** The suite has strong examples of each in isolation. A stored raw row can remain intact while its topic disappears from the prompt, its retained parent cannot reach it, or its public recovery output omits fields. (`T/test_ingest_protection.py:145`; `T/test_lcm_engine.py:12706`; `B/tools.py:1293,1393`.)

**The optional evidence systems have stronger falsifiable contracts than the summary-index path.** Exact-span rejection, explicit unknown state and stale-publication checks are already demonstrated elsewhere in B. (`T/test_assertion_extraction_state.py:413,502`; `T/test_evidence_pack.py:163`; `T/test_query_view_store.py:508`.)
